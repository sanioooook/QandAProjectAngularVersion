# Security Policy

## Supported versions

Only the [latest release](https://github.com/sanioooook/QandAProjectAngularVersion/releases/latest) gets fixes. Update by pulling the new `docker-compose.yml` from that release (see the README).

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/sanioooook/QandAProjectAngularVersion/security) of this repository, with steps to reproduce and the version you tested.

QandA is a personal project, so there is no guaranteed response time, but reports are read and valid ones are fixed in the next release.
